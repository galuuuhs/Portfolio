Automatic License Plate Recognition (ALPR) System
A computer vision system capable of automatically detecting and reading vehicle license plates, then verifying the vehicle's tax status in real-time through integration with the Sambara server (Samsat Mobile West Java). What sets this project apart: the entire dataset was collected independently — license plates were photographed directly in the campus parking area, then manually annotated with bounding boxes. This ensured the YOLO model was trained on data that's locally relevant and representative of real Indonesian conditions.

Mar 2025 · Edge Computing
Fall Detection System for Elderly
A wearable edge computing system for real-time fall detection in elderly individuals — no cloud dependency required. The standout feature is a dual-mode detection approach: instead of running ML on every movement, a threshold filter acts as the first gate, significantly reducing false positives and saving compute. The ML model was trained on the SisFall benchmark dataset, then converted to C code to run directly on the ESP32-S3.
Detection Flow
01 MPU6050 reads acceleration & gyroscope data
02 Threshold filter flags potential falls
03 Random Forest distinguishes real falls from normal movements

Nov 2023 · Digital Logic Design
8-bit Matrix Multiplication Processor
A fully custom digital processor for 8-bit matrix multiplication, designed bottom-up from individual logic gates — no pre-built IP blocks. Every arithmetic unit was constructed from scratch: NAND Gate → Half Adder → Full Adder → Demultiplexer → complete arithmetic unit. This modular approach allowed each layer to be independently verified before integration into the next, ensuring correctness at every level of abstraction.
Design approach
01 RTL design in Verilog HDL using Xilinx Vivado
02 Behavioral simulation to verify functional correctness
03 Static Timing Analysis to validate hardware constraints
Critical path 23.37 ns meets timing constraints for FPGA impl.

Sep 2024 · Telecommunications
FTTH Optical Fiber Network Design & Simulation
Designed and simulated a GPON-based Fiber-To-The-Home (FTTH) network intended to serve 357 residential units in Jatihandap, Cicaheum, Bandung — modeled after a real PT Telkom deployment area. The network architecture uses a two-stage splitting topology: OLT → ODC (1:4 splitter) → ODP (1:8 splitter) → ONT at each home. Distance data was sourced from Google Maps (STO Ahmad Yani Cicadas as the origin point), and the full link was simulated in OptiSystem for both upstream and downstream configurations.

Jan 2024 · Electrical Engineering
Residential Electrical Installation Design
A full electrical engineering design for a two-floor residential house — not a template, but a calculation-driven design built from scratch. Each of the 11 rooms was analyzed individually: required illuminance (lux), room area, and lamp efficiency were used to calculate the exact number and wattage of luminaires needed per room using the armature formula (N = E × A / Φ × Kp × Kd). All luminaires were specified from the Panasonic LED NEO series for energy efficiency.
